# Design Systems Library

## Sobre
Esta é uma coleção extraída do site [designmd.app/library](https://designmd.app/library/), que contém um catálogo extenso de **454 sistemas de design**. A biblioteca serve como um repositório de diretrizes visuais, tokens e estéticas prontas, ideais para acelerar o desenvolvimento de interfaces (UI/UX) e inspirar a criação de aplicações e sites utilizando Inteligência Artificial.

Para baixar: `document.querySelector('#download-designmd').click()`
